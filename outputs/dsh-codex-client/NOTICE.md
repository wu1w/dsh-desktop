# 来源与运行时

本地开发客户端，界面参照用户提供的两张截图实现。用户截图位于 `reference/`，不打入应用包。

- DeepSeek Harness 图标：来自本机已安装的 DeepSeek Harness 0.2.1-rc.2。项目源码：<https://github.com/deepseek-ai/deepseek-harness>。
- Cordis 与 DSH 凭据服务：`@deepseek-ai/cordis`、`@deepseek-ai/dsh-credentials-local`，保留各依赖包自带许可证。
- Codex 引擎：官方 `@openai/codex@0.163.0-alpha.11.2`，源码与许可证：<https://github.com/openai/codex>。运行时与正版 Codex 应用分开安装。
- Electron、React、Lucide：保留安装包自带许可证与版权声明。

界面未使用正版 Codex 的前端代码或资源。
