# DSH 独立桌面客户端

这是正在打磨和验收的独立客户端，使用真实 Codex 或 Claude Code 引擎、现有 OpenCode Go 额度和 DeepSeek V4.1 Flash。它有独立应用标识、图标、配置、会话及运行时，不修改原版 Codex 的 GPT 登录与使用。语音和云服务不在本轮范围。

当前应用在同目录上一级 `DSH-desktop/DSH-darwin-arm64/DSH.app`。本机可直接双击启动；初次使用可添加一个项目文件夹。默认数据目录是 `~/Library/Application Support/DSH-Codex/client`，自己的测试运行可用 `DSH_CLIENT_DATA_DIR` 指向独立目录。同一目录禁止多个宿主同时写入。

## 架构与插件

Electron 壳只连接本地宿主。`shell/` 动态加载外观插件；停用外观后仍有宿主插件恢复页，可重新启用。`server/plugin-host.mjs` 用真实 Cordis Fiber 管理插件生命周期，并追踪路由、外观、引擎与行为适配的注册和清理。

内置外观、项目、聊天/队列、文件预览编辑、项目终端、MCP/技能、MCP 问询表单、DeepSeek 行为配置和两种执行引擎均为插件。设置可以启停，安装的本地插件还能卸载。实际功能能力也通过 Cordis 注册：停用内置功能后，外部模块可用 registerFeature(内置功能ID) 接替，再提供相同接口，现有外观按当前提供者开放控件。声明清单本身不会获得运行能力；失败和停用会清注册。配置与模型凭据不放进前端包或报告。当前新宿主契约不等于所有旧 DSH 社区插件均已兼容；依赖原宿主服务的包仍须适配与实测。

终端、Git 和本地自动化通过显式停用检查确认资源收尾，再撤销 Cordis 注册。无法确认时保留活动、插件状态和记录，显示本地化错误并允许重试。PTY 需要新版原生守护进程的完成回执；仅转发进程退出不足以批准停用。宿主退出也会继续尝试其它资源的清理，最后报告失败；无法终止的进程仍须单独检查，不能把返回错误当成已清理成功。

外观以用户的 Codex 截图为布局和操作参考，统一系统字体、外缘圆角、平面灰阶、细边界和克制阴影；用户已允许非逐像素复刻。右侧文档和子智能体预览分别有合适的默认宽度并可拖动调整。

## 已有真实功能

- 项目目录、独立会话、搜索、置顶、未读通知、重命名、归档/恢复。
- 真实流式内容、工具事件、错误、停止、同原生会话续聊；Codex 原生历史分页与“加载更早”，默认只读最新20项，早页保留滚动位置。
- 运行中插入队列、编辑、删除和排序。Codex 引擎还支持原生即时引导；失败消息保留。
- 本地附件、Markdown/代码/表格预览、版本检查保存、未保存修改保护。
- 子智能体任务、右侧实时预览、打开聊天和停止。
- 两套引擎实际选择、按引擎隔离会话、能力不足时明确禁用操作。
- 多问题问答逐题选择/自定义/秘密输入/跳过与并发队列；仅发送实际填写的答案。审批有工具/文件/范围和有界内容预览；未支持的请求只能拒绝。断线后按服务器列表同步，清除已结束项，不把问答答案保存成草稿。
- Git 本地操作插件：已暂存/工作区/新文件分组与差异审阅，逐文件暂存/取消暂存；核对范围、说明和一次性身份后，仅提交已有暂存内容。仓库快照变化/外部锁会拒绝写入，失败保留输入且不自动重试。从核对提交返回编辑会重新读取原选中文件的差异；失败可重试，提交草稿保留，不自动暂存或提交。转换器、冲突、子模块和linked worktree等明确限制写能力；尚无分支切换/工作树/推送。
- Codex 原生 MCP 配置/登录入口、技能发现与启停；功能插件停用会重置对应原生配置，恢复后重新应用。
- 原生文件选择、菜单、查找、快捷键、语言和窗口状态保存。
- 外观热插拔保留正文/附件草稿；未保存文档另存到独立数据目录，可跨随机端口恢复。保存/放弃会串行清除对应备份，正常退出先等待落盘；损坏备份保留并显示错误，文件浏览仍可用。

Codex 引擎使用固定的独立 `@openai/codex@0.163.0-alpha.11.2`。Claude Code 适配使用固定 SDK `0.3.309` 与本机已安装 CLI（本次验证 `2.1.295`），独立 `CLAUDE_CONFIG_DIR`；真实文件工具有原生 restricted 限制和审批。当前 Claude 适配不提供模型任意终端命令、即时引导、分叉、跨项目移动、图片输入、MCP/技能管理或完全系统访问。前端显示能力差异，不能将其冒充完整等价。

DeepSeek 行为适配是单独插件，只影响新建 Codex/Flash 会话；版本、哈希和原文在线程映射中固定，恢复和分叉不更换历史配置。停用后新聊天回到原生默认。`low/high/max` 档位有真实协议及联调证据；尚未将未经路由验证的 1M 上下文承诺为实际可用容量。

## 当前仍需打磨

Git 分支切换/工作树/推送、集成浏览器与原生电脑操作、MCP扩展/URL问询及动态工具、富文档的完整编辑链、全部原 DSH 社区插件兼容、长时间稳定性、安装升级与迁移仍未达到完整验收。跨端口草稿恢复已有控制器、实际文件落盘/SIGKILL和HTTP重启测试，锁屏后尚未复验新包的实际GUI。

长历史已对旧格式与原生分页格式各240轮/480项的24–48MB种子实际验证，未发模型请求。旧格式逐turn读取，因此单个超大turn仍可能触发1MB限制；单项超限会明确显示错误，不伪装为完整读取。Claude历史暂仍读取自己的完整文件。

Git审阅禁用仓库可执行的hooks、fsmonitor、外部diff、textconv与clean/process/smudge转换器，不修改index。显式暂存/取消暂存会更新index，显式本地提交会更新分支；不调用用户hook、签名、编辑器或网络。写操作只支持普通SHA-1仓库及Git≥2.30，单文件16MiB、快照总32MiB、metadata遍历5万项上限，转换属性/CRLF配置等不支持时会禁用写入。Git提交说明与一次性身份通过独立git-drafts.json按项目自动保存，关闭面板、外观重载和宿主重启可恢复；正常退出等待落盘，失败保留输入并阻止静默退出。并发旧版本拒绝覆盖；显式读取另一份前有替换确认。最多64项目，每项目三字段合计64KiB、作者字段各1KiB，总文件8MiB；不写项目Git配置或聊天偏好。失败的plumbing可能留下未引用对象，不冒称零对象库写入。转换仓库展示原始工作区比较，不能冒充LFS/自定义转换后的等价状态；特殊转换器名无法安全覆盖时明确拒绝。

项目终端已新增真实交互式 PTY，支持输入、Ctrl+C、尺寸调整、重连、多个会话与停止；普通命令API保留。后端原生进程及新包HTTP通过，最新xterm界面仍待解锁复验。终端使用本机账户权限；主动脱离PTY session的daemon不在关闭清理保证内。

新增本地自动化插件：创建默认暂停，显式开启或手动运行；仅宿主运行时调度，错过不补跑，原生终态才记完成。持久claim、聊天绑定失败不发模型请求，崩溃遗留标unknown不重发，停用中止自己的运行并保留记录。间隔15分钟至7天或本机时间每天，尚无cron表达式、后台launchd或远程执行。详见上一级《DSH-本地工具核验》。Claude Code 的能力缺项和模型目录元数据仍需继续补齐。应用已完成本机打包与资源校验，但尚无开发者分发签名/公证，不作为已完成的公开发行版本。

## 开发与核验

```sh
npm ci
npm run build
npm test
node scripts/package.mjs
```

`build` 把两套引擎纯源码复制为自己的运行依赖并生成外观 ESM；`package` 校验本地应用资源、入口依赖、独立引擎版本、标识与签名实况。不得只更新源码便宣称正在运行的新包生效。

测试涵盖真实 Cordis 生命周期、并发/失败清理、权限与文件版本、目录锁、插件落盘失败回滚、IPC 与关闭握手；真实模型联调记录见上一级《DSH-Codex-核验记录》《DSH-DeepSeek-适配与对照》《DSH-Claude-Code-引擎核验》。这些证据都不能代替剩余功能与长期稳定性验收。

插件接口见 [PLUGIN-API.md](PLUGIN-API.md)。交互终端固定使用 @xterm/xterm 6.0.0 / addon-fit 0.11.0 与本机forkpty辅助程序；[官方接口文档](https://xtermjs.org/docs/guides/using-addons/)。xterm动态字体/配色规则需要允许页面内样式；脚本仍仅允许self，Electron沙箱与隔离继续启用。


## 启动恢复与退出

聊天索引损坏时仅提供宿主恢复页，执行引擎、功能插件和后台调度保持停止。可重新读取、显式恢复上一份有效备份，或显式创建新索引。恢复前将当前异常文件精确另存为私有client-corrupt-*.json，项目正文和独立引擎目录不删除。client.json与备份必须是普通单链接文件；8MiB上限、路径异常或文件变化会拒绝覆盖。其它配置同时损坏时保留文件并停止初始化，不能把“索引已恢复”冒充整个应用已修复。

退出按真实Cordis活动提供者与每个原生Turn核对所有模型、终端、命令和自动化；确认期间新增任务会重新确认。重新加载界面保留后台任务。文档放弃授权绑定编辑版本，保存握手期间暂停整个外观交互，包括浮层菜单、已开和新开的原生网页弹窗、主界面快捷键与桌面菜单回调；Escape 关闭也在握手期间暂停；失败或取消后按各元素原状态恢复，并尽力回到仍存在的原焦点控件。新编辑不沿用旧授权。最新原生弹窗/恢复页仍待解锁后GUI复验，自动测试与包内接口成绩详见上一级《DSH-启动恢复与退出核验》。

回答、文档与子智能体预览中的项目文件引用会进入现有版本化文件预览流程，文档相对路径以所在文件夹解析；项目外路径、元数据路径和伪协议不执行。:line、:line:column及#Lline范围引用可在源文件中定位/选择，列按Unicode字符计算；当前未保存缓冲内跳转不会重读或丢失编辑。源文件支持有界行号栏与本地⌘/Ctrl+G跳行，代码/普通文本按原文只读预览，Markdown可切换编辑与格式预览。文本编辑限2MiB严格UTF-8；非法编码、NUL和孤立surrogate明确拒绝，保留BOM与未改行尾，新换行沿用文件首个行尾。网页/邮件链接仍是显式外部链接；这不是完整富文档渲染。原DSH界面插槽/Loader插件缺少兼容层时给出明确安装说明，详见上一级《DSH-插件兼容边界》。

事件流有45秒静默看门狗与15秒bootstrap期限；心跳会保持连接。重新订阅后补读状态、当前聊天/队列及打开的子智能体记录，补读15秒截止，SSE更新优先于旧快照。只补读，不重放消息、审批或写操作；失去的中间增量不冒充完整重放。

系统应用打开由文件插件管理：等待系统启动器退出成功后才显示请求已被接受，失败/超时给出本地化反馈；未保存内容先选择保存、放弃或取消，等待期间禁止重复提交。此确认不代表外部窗口已显示。插件停用仅收尾自己的启动器，不关闭已移交的独立应用。

插件停用前可以注册显式资源确认；清理失败时保留原插件和活动并显示错误，资源实际退出后可重试停用。不是所有第三方effects都能验证释放，宿主最终关停仍有强制撤除注册的边界。

项目文件浏览提供文件预览、选作附件、复制相对路径和系统打开菜单，含目录位置、上一级、刷新、加载／失败重试及键盘导航。每次请求绑定项目和目录，关闭、切项目或停用功能后，迟到列表不会重新打开旧内容。目录枚举仍有现有2000项上限，尚无完整分页。

无法安全预览的二进制、非UTF-8和过大普通文件显示只读文件信息与明确的系统打开入口，不伪造正文或允许文本保存。元数据接口不读取正文，原有文本恢复副本在正常刷新/退出/外观重载时保留；文件恢复为可编辑文本后可重试。启动时自动恢复跳过不能预览的候选，继续其它可恢复文本。静态 PNG、JPEG、WebP 由独立图片插件提供只读应用内预览；PDF、Office 和动画图片的完整应用内渲染仍未实现。

Mac/Linux原始相对文件名（如字面反斜线、冒号或换行）在文件恢复与附件偏好中按实际平台规则保存；控制字符在文件浏览中显示为可辨认转义，实际路径保持原样。NUL、原生绝对路径、上级段和超4KiB路径仍拒绝。附件每聊天最多50项，每批上传最多20项、总10MB；项目选择和上传同步防重复/超量，非法偏好不会局部落盘。Markdown文件引用仍有受限语法。


## 图片预览插件

`feature-images` 是可独立启停和替换的 Cordis 功能，与文本文件编辑分开管理。内置外观通过带本机授权的请求读取图片，核对大小、类型和内容 SHA-256 后才创建临时 Blob URL；没有把凭据或图片正文放入 URL。静态 PNG、JPEG、WebP 提供适应窗口、原尺寸、缩放、滚动及尺寸/大小/修改时间；预览获得焦点时 +/−、0、1 对应缩放、适应与原尺寸。图片只读，保留同路径已有文本恢复副本。

单图最多16MiB、3200万像素、单边16384像素，同时最多4个读取或传输；不接收动画PNG/WebP、SVG、GIF或未支持的编码子集。服务端验证容器和编码头，浏览器负责实际解码；失败明确提示并允许重新读取。停止插件会取消其读取与未完成传输、确认文件句柄释放；失败保留活动和插件状态以供重试。图片切换、关闭和停用后撤销自身 Blob URL。独立图片提供者的接口与限制见 PLUGIN-API.md。


数据目录锁失效时停止本实例，不自动抢回或放宽锁检测。启动尚未完成时失锁也拒绝返回可用宿主；新请求拒绝执行。退出保留首次 `DATA_LOCK_LOST` 原因，避免将原始失锁误报为二次释放错误。它不保证同步软件或外部进程不会修改锁目录；独立数据目录应由本实例独占。

### 长会话与事件传输

发行包使用生产版 React。已加载消息保留完整 DOM，不做截断或虚拟列表；稳定消息记录与逐条 memo 避免输入、菜单及无关状态反复解析整段历史。文件动作仍按消息所属项目校验。内联 Markdown 使用线性扫描，未闭合标记显示原文，链接继续经过原有协议和项目路径验证。子智能体预览默认跟随尾部，向上阅读暂停跟随；加载更早优先保留阅读锚点。

SSE 的底层 write 返回 false 表示当前帧已接收、后续帧需要等 drain，不表示断线，也不重发该帧。每连接待发与 Node 写缓冲合计上限8MiB、最多256待发帧，单帧上限4MiB；持续阻塞10秒则仅关闭该连接。已有只读补同步处理重连，不重放写操作。HTTP 队列快照与发消息回执不能覆盖其等待期间收到的更新原生事件。上述措施不承诺无限历史下恒定开销，也不代表模型能力或所有设备上的时延保证。

### 键盘与中文组合输入

菜单可用方向/Home/End、按文字查找、重复首字母循环；向上键打开最后一项，向下键打开第一项。Tab/Shift+Tab按触发按钮在页面中的顺序继续，Escape关闭并归还焦点。全禁用菜单仍可关闭；原生更新使当前选项不可用时保持菜单内可操作的键盘焦点。关闭/卸载会释放搜索计时器、定位观察器与监听器。

主输入框、队列编辑、查找与文档跳行共享组合输入判断，包括原生/React isComposing及229兼容码；组合中按键不当作发送、保存、取消或DOM全局快捷键。文档跳行另外跟踪compositionstart/end，不用猜测时间窗口。引擎不匹配时键盘与表单也拒绝发送，保留草稿。真实macOS输入法的全部事件顺序仍需解锁后验收。


## MCP 标准问询表单插件

`feature-mcp-forms` 独立注册标准 `mcpServer/elicitation/request` 处理器和界面能力；可停用、重新启用或由本地插件替换。停用实际移除处理器，旧接受请求被拒绝；原生请求保留，界面清除尚未发送的输入，仍可拒绝或取消。重新启用需重新填写，不会从恢复草稿取回答。

当前支持 `mode:form` 的平面字符串、有限数值/安全整数、显式布尔、带标题的单选与多选，校验必填、字符/数值/数量范围、类型及额外字段。零、false、空文本、空列表与省略分别处理；服务器建议默认值只提示，不自动填写。最多20字段、每项100选项、字符串20KB、回答总100KB。未知约束、format、嵌套对象、URL验证及扩展表单会明确回退为拒绝/取消，不启用扩展表单能力。

回答仅在本次请求内存中保留，不写入聊天偏好/草稿或广播；接受后信息按原生协议交给请求方 MCP 服务器。服务器可按其工具行为使用这些信息，客户端不承诺从下游工具或模型上下文抹除。原生 `approvalPolicy:never` 会自动拒绝，此模式下不会出现表单；内置引擎保持原有 on-request 配置。


## 2026-10-24：任务恢复与持续运行

新增每个聊天的持久运行检查点，位于原有原子保存的 `client.json`。在发送前先保存状态；停止意图同样先落盘。状态区分运行、等待恢复、中断、失败、结果待核实与完成。正常结束的任务不续跑，用户停止、停用聊天/引擎或正常退出后不自动恢复执行。

Codex 的已确认网络故障先由原生引擎重试（默认请求6次、流8次、流空闲5分钟）；回合确实以网络错误结束后，宿主按5秒至5分钟退避自动续跑。每次续跑前查询原生精确Turn ID、确认终态和无排队消息，沿用原线程、模型、权限与推理档位，发送核对已完成工作后继续的指令。不会把原始输入、审批或工具命令重放。固定原生版本把两类传输错误标为 `other`，仅对实测的严格网络错误格式兼容；认证、额度、上下文、策略和普通工具失败不会因此无限重试。

本地引擎异常退出后以1秒至30秒退避拉起，并查询持久任务的原生状态；原生确认已完成则只同步完成，确认因崩溃中断才续跑。无法确定请求是否接收/执行的状态保留为待核实，不冒充成功或重复启动。界面新增继续任务与等待期间停止操作，中英文均可用。原生状态分页每页1.5秒、总8秒，冷启动/线程恢复仍有独立期限；读超时不杀正在工作中的引擎。

Claude 适配取消默认整轮5分钟与32轮上限，改为进展刷新空闲期限和可选总期限，进度阶段落盘，取消/关闭有界。它的传输错误仍未与Codex完整等价，无法可靠分类的失败保留为手动继续。自动化默认不再30分钟硬停；单个失效任务不再阻塞其它任务。自动化崩溃后的未知结果保持待核实，不重复执行整个计划。

界面与宿主壳共享有上限的事件流、退避重连和补同步；只重试读取。桌面在实际运行、等待网络恢复与引擎重启期间防止空闲睡眠。已结束会话的正文缓存默认100会话/估算32MiB，原生历史保留，活动和正在加载的会话可暂时超预算。

需要覆盖整个桌面主进程异常退出时，从发行目录的 `DSH-长期运行.command` 启动；直接双击 `.app` 不启用外层守护。守护器仅拉起自己的应用，正常退出不重启，异常退出退避重启；不安装登录项或修改系统网络。详情见 `desktop/PROCESS-SUPERVISOR.md` 与 `DESKTOP-RELIABILITY.md`。正常关闭或机器关闭/主动睡眠期间不执行。

最新验证与实际边界见上一级《DSH-长期运行与故障恢复核验》。短时故障矩阵和循环压力测试不能替代数日实机持续验收；聊天索引8MiB上限、单个超大活动消息、Claude完整历史和未知插件副作用仍是明确边界。

## 消息通道

设置 → 消息通道提供飞书、QQ、微信、钉钉、企业微信五个内置插件。每个插件可独立启停；账号默认不连接。配置项目、模型和允许的用户后连接。微信先保存配置，再扫码授权，再连接。飞书需要开放平台机器人的长连接和消息订阅权限；QQ 使用官方机器人 App ID / Client Secret。允许用户填写平台的机器人用户 ID，不是手机号或普通 QQ 号码。普通微信群暂不支持。钉钉使用企业应用机器人的 Stream 模式（Client ID / Client Secret）；企微使用智能机器人 API 长连接模式（Bot ID / Secret），不包括自建应用 HTTP 回调。长任务回复凭据失效时，结果保留在待投递队列；在原会话发送 `/status` 可刷新凭据。

IM 会话在侧栏独立分类，显示平台、联系人和群标识。不同平台、联系人、群和话题使用独立原生会话；群内不同发信人也隔离上下文。`/status` 查看状态，`/stop` 保存停止意图，`/resume` 核对原任务后继续，`/new` 开始新聊天。权限审批仍在桌面端处理。

接收记录、任务检查点和回复投递分别保存。断网和通道进程退出后会自动重连；主动断开保持关闭。发送超时或进程退出导致投递结果不明时，设置页显示“待核实”，可核对后重发、标记已送达或取消；这些操作不会重新执行模型任务。关闭插件会停止该插件拥有的执行；普通“断开”仅关闭通信，已开始的任务仍可完成并保存待投递回复。

来源、复制范围、许可、部署和限制详见相邻 `dsh-channel-runtime/README.md`。已保存的凭据不会在设置 API 中返回，但本机私有 SQLite 使用文件权限保护，未加密存储。本版本一平台一个账号；不支持直接替换账号身份，以免旧回复发往错误账号。
